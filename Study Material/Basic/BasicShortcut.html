Function Keys (F1–F12) EGyan

The row at the top of your keyboard isn't just for show — these keys do critical jobs everywhere.

Open Help in most applications
F1
Rename selected file or folder
F2
Search / Find in most apps
F3
Focus address bar (in Explorer / browsers)
Alt+F4
Refresh / Reload
F5
Move focus to address bar / next pane
F6
Spell check / grammar (MS Word)
F7
Extended selection (boot menu on startup)
F8
Update fields (MS Word)
F9
Activate menu bar / Ribbon
F10
Full-screen (browser)
F11
Save As / Open DevTools (browser)
F12
Laptop note: Many laptops require Fn + F1–F12 because the F-row doubles as brightness, volume, and other controls.
