1. What is MS Excel?

Microsoft Excel is a spreadsheet program developed by Microsoft. It organizes data into a grid of rows and columns where each intersection is a cell. Excel can perform calculations, create charts, analyze trends, and manage huge datasets.

It's part of the Microsoft Office suite and has been the world's most widely used data tool since 1985. From small shops tracking inventory to Wall Street analyzing millions of rows, Excel is everywhere.

Excel files are called workbooks (`.xlsx`). Each workbook contains one or more worksheets (tabs at the bottom).

Fun fact: Excel has 1,048,576 rows and 16,384 columns per sheet — that's over 17 billion cells in one worksheet!
The Excel window. Ribbon on top, formula bar below it, column letters A–F across, row numbers down the left, and sheet tabs at the bottom.

2. Excel Anatomy

Before typing a single number, you should know where everything lives on the Excel screen.

Ribbon

The toolbar at the top with tabs: Home, Insert, Page Layout, Formulas, Data, Review, View. Every command is organized here.

Name Box

Shows the address of the active cell (e.g., A1). Type a cell reference here to jump directly to it.

Formula Bar

The long input box where you type or edit formulas. Starts with the fx icon. Shows the actual formula of the selected cell.

Worksheet Grid

The main area — an infinite grid of cells where each cell has a unique address like C5.

Column Headers (A, B, C …)

Letters across the top. Click to select the entire column. Excel supports columns up to XFD (16,384 columns).

Row Headers (1, 2, 3 …)

Numbers on the left. Click to select the whole row. Rows go up to 1,048,576.

Sheet Tabs

Bottom of the window — each tab is a separate worksheet. Click + to add a new one. Right-click to rename, move, color, or delete.

Status Bar

Bottom strip showing useful info: Average, Sum, Count of selected cells, plus the zoom slider on the right.

Cell

The smallest unit — where you type data, formulas, or text. Each cell is uniquely identified by its column + row (e.g., B3).

Range

A block of cells, e.g., A1:D10. Used in formulas — =SUM(A1:A10) adds everything in column A, rows 1–10.

Quick tip: Press Ctrl + Home to jump to cell A1 from anywhere, and Ctrl + End to jump to the last used cell.

3. Formulas & Functions

This is where Excel becomes magical. Every formula begins with the = sign. Excel has 400+ functions — but you only need the top 15 in 90% of real work.

The Big 15 Functions

SUM

Adds numbers in a range.

=SUM(A1:A10)

AVERAGE

Mean of numbers in a range.

=AVERAGE(B1:B20)

COUNT / COUNTA

COUNT counts numbers; COUNTA counts non-empty cells (including text).

=COUNTA(A1:A50)

MAX / MIN

Largest / smallest value in a range.

=MAX(C1:C30)

ROUND

Rounds a number to N decimal places.

=ROUND(A1, 2)

IF

Returns one value if a condition is true, another if false.

=IF(A1>60, "Pass", "Fail")

IFS

Multiple conditions in one formula (Excel 2019+).

=IFS(A1>=90,"A", A1>=75,"B", TRUE,"C")

VLOOKUP

Searches for a value in the first column of a table and returns a value from another column.

=VLOOKUP(A2, Sheet2!A:D, 3, FALSE)

XLOOKUP (Modern)

Successor to VLOOKUP. Searches in any direction.

=XLOOKUP(A2, B:B, D:D, "Not found")

INDEX + MATCH

Powerful, flexible alternative to VLOOKUP — no column-order limits.

=INDEX(D:D, MATCH(A2, B:B, 0))

SUMIF / SUMIFS

Sums values that meet one or more conditions.

=SUMIF(A:A, "Delhi", B:B)

COUNTIF / COUNTIFS

Counts cells that meet a condition.

=COUNTIF(A:A, ">100")

CONCAT / TEXTJOIN

Joins text from multiple cells. TEXTJOIN lets you specify a separator.

=TEXTJOIN(", ", TRUE, A1:A5)

LEFT / RIGHT / MID

Extract part of a text string.

=LEFT(A1, 5)

TODAY / NOW

Current date / current date + time. Updates automatically.

=TODAY()
Common error codes: #DIV/0! = divide by zero · #VALUE! = wrong data type · #REF! = broken cell reference · #N/A = value not found (VLOOKUP) · #NAME? = typo in function name.

4. Key Excel Features

Beyond cells and formulas, Excel has powerful built-in tools that turn raw data into insight.

Charts & Graphs

Turn data into bar, line, pie, scatter, and 20+ chart types. Insert → Charts. Great for reports and presentations.

Pivot Tables

Excel's superpower. Summarize thousands of rows into a compact table — totals, averages, counts by category — in seconds.

Conditional Formatting

Auto-color cells based on rules — highlight values above average, color scales, data bars, icons.

Data Filtering

Instantly filter rows by any column value. Perfect for narrowing down big datasets to what you need.

Sorting

Sort alphabetically, numerically, by date, or by custom order. Multi-level sorting available.

Data Validation

Restrict what can be entered in a cell — dropdown lists, date ranges, number limits. Prevents bad data.

Find & Replace

Search any value across the whole sheet. Replace en masse. Supports wildcards (* and ?).

Sheet / Workbook Protection

Lock cells, protect sheets, add password to workbook. Prevents accidental edits.

Print Setup

Print ranges, set page breaks, define print areas, headers/footers. Make reports look professional.

What-If Analysis

Goal Seek, Scenario Manager, Data Table — test how changing inputs affects results.

Macros (VBA)

Record or code repetitive tasks. Runs automatically with one click. Power users automate whole workflows.

Co-authoring (365)

Multiple people edit the same workbook simultaneously in real time — with live cursors and comments.

6. Tips & Real-World Uses

Excel is used across every industry. Here are the most powerful tips to level up quickly:

Learn the Mouse-Free Way

Press Alt alone to see shortcut hints on the ribbon. Then follow them — you'll never need the mouse.

Use Tables (Ctrl + T)

Convert data to an Excel Table — auto-filters, auto-formats, and formulas auto-fill as you add rows.

Named Ranges

Give a range a name like sales_total and use it in formulas instead of A1:A100.

Paste Special → Values

Copy a formula result and paste only its value — breaks the formula link. Use Ctrl+Alt+V.

Freeze Panes

View → Freeze Panes → Freeze Top Row. Headers stay visible as you scroll down thousands of rows.

Common Uses

Budgeting, sales reports, inventory, salary sheets, marksheets, attendance, loan calculators, data cleaning, and dashboards.

Always Check Formulas

Click any result cell and read the formula bar. Excel never lies — but one wrong reference can break a report.

Save Often, Save as .xlsx

Never use the old .xls unless you must. Modern .xlsx is faster, smaller, and safer.
