Data Management & Cleaning

Messy data is the enemy of good analysis. Learn to use Power Query, TRIM, Flash Fill, and Text to Columns to turn dirty exports into pristine datasets.

1. Power Query: The ETL Tool

Power Query is Excel's most powerful data cleaning tool. It's an ETL (Extract, Transform, Load) engine built directly into Excel that records every step you take, so you can reapply the entire cleaning process with one click when new data arrives [citation:2][citation:10].

Instead of writing fragile, nested formulas, you use the Power Query Editor's ribbon to remove duplicates, split columns, trim spaces, and change data types. The original data stays untouched — Power Query is non-destructive [citation:14].

Where to find it: Go to Data → Get Data → From File (or any source). Instead of clicking "Load," click Transform Data to open the Power Query Editor [citation:10].
Power Query workflow. Extract from any source, transform with recorded steps, load a clean table — repeatable forever.

Applied Steps

Every click is recorded on the right pane. Click any step to preview, delete it, or reorder — no undo needed [citation:10].

Column from Examples

Type one or two examples of what you want extracted, and Power Query writes the transformation code for you [citation:14].

Remove Other Columns

Instead of deleting columns one by one, select the columns to keep and right-click → Remove Other Columns. Future source changes won't break it [citation:2].

2. Text & Space Cleaning

Extra spaces and non-printable characters are invisible culprits that break sorting, filtering, and lookups. A cell that looks like "USA" might actually be " USA " with a trailing space [citation:4][citation:8].

The fix is a combination of three functions: TRIM removes extra spaces, CLEAN removes non-printable characters, and SUBSTITUTE handles specific replacements [citation:4].

Essential Text Functions

TRIM — Removes leading, trailing, and multiple internal spaces. =TRIM(A2)
TRIM
CLEAN — Removes non-printable ASCII characters (codes 0–31). =CLEAN(A2)
CLEAN
SUBSTITUTE — Replaces specific text. =SUBSTITUTE(A2, "-", "") removes hyphens
SUBSTITUTE
UPPER / LOWER / PROPER — Standardize capitalization. =PROPER(A2) makes "john doe" → "John Doe"
PROPER
VALUE — Converts text-formatted numbers to real numbers. =VALUE(A2)
VALUE
Pro tip: If TRIM doesn't remove a stubborn space, it's likely a non-breaking space (Unicode 160). Use =SUBSTITUTE(A2, CHAR(160), " ") first, then wrap with TRIM [citation:4].

When multiple pieces of data are crammed into one cell — like "John, Smith, 30" — you need to split them into separate columns. Excel offers two tools: Text to Columns (delimiter-based) and Flash Fill (pattern-based) [citation:3][citation:7].

4. Deduplication & Data Types

Duplicate rows are a common problem after importing data. But order matters: clean text and fix data types before removing duplicates. Otherwise, "USA" and " USA " are treated as different values [citation:3].

Select data → Data → Remove Duplicates
Menu
Choose which columns define a duplicate (select all for exact matches)
Columns
First, use Filter → Unique values to preview what will remain
Preview
Data Type fixes: Numbers stored as text won't calculate. Dates stored as text won't sort. Use Data → Text to Columns → Finish to force conversion, or in Power Query, click the data type icon in the column header [citation:4].
Order of operations: 1. TRIM/CLEAN text → 2. Fix data types → 3. Split columns → 4. Remove duplicates. Skipping steps 1–2 means duplicates slip through [citation:3].

6. Tips & Workflow

These practices prevent data disasters and make your cleaning repeatable:

Protect the Original

Never clean the raw file. Save a copy as "WorkingFile.xlsx" and keep a "Raw Data" tab untouched. You'll always have a reset button [citation:8].

Clean Before Dedupe

TRIM spaces and fix case before Remove Duplicates. Otherwise "usa" and "USA" survive as separate rows [citation:3].

Use Power Query for Recurring Tasks

If you clean the same report monthly, build it once in Power Query. Next month, just click Refresh [citation:2][citation:10].

Find Blanks with Go To Special

Select data → Ctrl+G → Special → Blanks → type "N/A" → Ctrl+Enter to fill all at once [citation:8].

PROPER for Names

"john smith" → "John Smith". Use UPPER for product codes, LOWER for emails [citation:4].

Avoid Merged Cells

Merged cells break sorting, filtering, and PivotTables. Use "Center Across Selection" instead for visual layout.

Critical check: After cleaning, verify row counts. Compare the original data row count with the cleaned version. If numbers don't match, you may have accidentally removed valid rows or missed duplicates.
Practice plan: Download a messy CSV export. Build a Power Query that: removes top rows, promotes headers, splits a combined column, trims text, and removes duplicates. Save the query and refresh it with a new file to confirm it's repeatable.
