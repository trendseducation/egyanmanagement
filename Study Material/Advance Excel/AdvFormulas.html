1. Dynamic Arrays (Excel 2021+)

Dynamic Arrays represent the biggest change to Excel's calculation engine in decades. Instead of writing one formula and dragging it down, you write one formula that spills results into adjacent cells automatically [citation:2][citation:6].

The blue border you see around spilled results is called the spill range. When source data changes, the spill range expands or contracts instantly. This eliminates helper columns and manual copy-paste workflows [citation:7].

Version check: Dynamic arrays are available in Microsoft 365, Excel 2021, Excel 2024, and Excel for the web. If you see a #SPILL! error, something is blocking the range — clear the cells below and the formula will flow [citation:2].

Core Dynamic Array Functions

FILTER

=FILTER(array, include, [if_empty])
Returns rows that meet a condition. Replaces the Filter button with a live, formula-driven view [citation:7].

UNIQUE

=UNIQUE(array)
Extracts distinct values. The list updates automatically when new data arrives — no more "Remove Duplicates" [citation:6].

SORT & SORTBY

=SORT(UNIQUE(A:A)) chains functions. SORTBY sorts by a separate column, which is more resilient to layout changes [citation:1][citation:7].

SEQUENCE

=SEQUENCE(rows, [cols], [start], [step])
Generates number series. Great for creating dynamic date tables or test data [citation:6].

Chaining example: =SORT(UNIQUE(FILTER(A2:A100, B2:B100="Sales"))) gives you a sorted, unique list of Sales reps from a filtered range — all in one cell [citation:1].

2. Modern Lookup: XLOOKUP

XLOOKUP is the successor to VLOOKUP and HLOOKUP. It solves the most frustrating limitations of older lookup functions: no column counting, no left-lookup limitation, and built-in error handling [citation:4][citation:9].

The syntax is simpler: =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found]). It works by default on unsorted data and returns an exact match without any extra arguments [citation:9].

No Column Counting

Unlike VLOOKUP, you select the entire return column directly. Inserting a column later won't break the formula [citation:9].

Looks Left or Right

VLOOKUP can only look to the right. XLOOKUP has no such limitation — the return array can be anywhere [citation:4].

Built-in Error Handling

Add a 4th argument: =XLOOKUP(A2, IDs, Names, "Not Found"). No need to wrap in IFERROR [citation:4].

Return Multiple Columns

XLOOKUP can spill an entire row of data if the return array spans multiple columns — perfect for dashboards [citation:7].

Compatibility note: XLOOKUP is not available in Excel 2019 or earlier. If you share files with legacy users, use INDEX/MATCH as a fallback [citation:9].

3. LET & LAMBDA (Formula Sanity)

LET lets you name intermediate calculations inside a formula. If you've ever written AVERAGE(B2:E2) three times in one IF statement, LET cleans it up [citation:13].

Syntax: =LET(name1, value1, name2, value2, calculation). You define a variable once and reuse it. This makes long formulas readable and faster to calculate [citation:8].

Before LET: =IF(AVERAGE(B2:E2)>85, "A", IF(AVERAGE(B2:E2)>=70, "B", "C"))
After LET: =LET(avg, AVERAGE(B2:E2), IF(avg>85, "A", IF(avg>=70, "B", "C"))) [citation:13]

LAMBDA: Custom Functions Without VBA

LAMBDA lets you create your own reusable function and save it in the Name Manager. Define it once, use it everywhere [citation:8][citation:13].

Open Formulas → Name Manager → New
Ctrl+F3
In "Refers to", enter: =LAMBDA(amount, rate, amount*rate)
Custom
In any cell, type: =TAX(B5, 0.18) — it works like a native function
TAX()
Power combo: Use LET inside a LAMBDA to name intermediate steps, then save it. The result is a readable, documented custom function that anyone on your team can use [citation:8].

4. Financial Functions (Must-Know)

These are the core functions for loans, investments, and project evaluation. The critical rule: signs matter. Money you pay out is negative; money you receive is positive [citation:5].

PMT — Loan payment. =PMT(rate/12, nper, -pv)
PMT
FV — Future value of an investment. =FV(rate, nper, pmt, -pv)
FV
NPV — Net present value. =NPV(rate, cashflows) + initial_investment
NPV
IRR — Internal rate of return. =IRR(cashflow_range)
IRR
XNPV / XIRR — For irregular, date-based cash flows
XIRR
Sign convention trap: If =PMT(6%/12, 60, 25000) returns a negative number, that's correct — it represents cash leaving your pocket. To display a positive EMI, use =-PMT(...) or enter -25000 for the present value [citation:5].
Rate alignment: Monthly payments need a monthly rate (annual/12) and a period count in months. Mixing annual rates with monthly periods is the #1 source of financial formula errors [citation:5].

6. Tips & Best Practices

These habits separate clean, auditable spreadsheets from fragile ones:

Use Excel Tables (Ctrl+T)

Tables give you structured references (Sales[Amount]) instead of cell addresses. Formulas auto-fill and survive row insertions [citation:8].

Name Your Variables with LET

Any formula with the same calculation repeated twice is a candidate for LET. It reduces errors and makes the logic readable to others [citation:13].

Test XLOOKUP Before Sharing

If you share files with Excel 2019 users, XLOOKUP will return #NAME?. Use INDEX/MATCH or provide a legacy version [citation:9].

Break Formulas with F9

Select a portion of a formula and press F9 to evaluate it. This is the fastest way to debug nested logic [citation:11].

Avoid Merged Cells in Data

Merged cells break sorting, filtering, and dynamic arrays. Use "Center Across Selection" instead for visual layout [citation:7].

Respect the Sign Convention

In financial functions, outflows are negative. If your PMT is positive, you entered the PV as positive — which is mathematically incorrect [citation:5].

Critical check: Before sending a financial model, verify that rates and periods match. A monthly payment calculated with an annual rate will be off by a factor of 12. Double-check every PMT, FV, and NPV input.
Practice plan: Build a loan amortization table with PMT. Create a dynamic dashboard with FILTER and SORT. Write a custom LAMBDA for tax calculation. Compare XLOOKUP vs INDEX/MATCH on the same dataset.
