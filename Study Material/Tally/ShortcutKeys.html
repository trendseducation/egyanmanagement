1. How to Use Shortcut Keys

TallyPrime is built with a keyboard-first design. Every voucher, report, and screen has a dedicated shortcut — no mouse required. Once you learn them, they become muscle memory, and your speed multiplies [citation:4][citation:8].

The shortcuts below are a comprehensive reference covering GST tasks, core vouchers, reports, and hidden keys. They assume GST is enabled in your company (F11 → Enable GST = Yes). Some shortcuts work only on specific screens — the context is noted in each group [citation:1][citation:4].

Press ? (question mark) anywhere in TallyPrime to see the complete shortcut list for that screen. The list below is curated for daily work — keep it handy during return filing and reconciliation.

Tip: Use the search box above to find any shortcut instantly. Type "F8" for sales, "GSTR" for returns, or "Alt+E" for export. The page filters live as you type.
